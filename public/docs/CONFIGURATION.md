# Настройки: .env

Все настройки — переменные в `.env` (копия `.env.example`, там у каждой есть
комментарий). Пустое значение — функция выключена или берётся значение по
умолчанию. **После правки `.env` выполните `docker compose up -d`**:
`restart` окружение не перечитывает.

Ниже — всё, что стоит знать, по группам. Пути к базе, сессии и токенам в Docker
задаёт `docker-compose.yml`; менять их в `.env` не нужно.

## Безопасность отправки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `DRY_RUN` | `false` | `true` — всё готовится и пишется в лог, но ничего не уходит. Для первого запуска |
| `KILL_SWITCH_PATH` | `STOP_SENDING.flag` | стоп-кран: файл существует — молчит вся отправка. Также кнопка/команда `/stop` в боте |
| `TELEGRAM_COLD_ENABLED` | `false` | холодные сообщения рекрутёрам с личного Telegram. См. [SAFETY.md](SAFETY.md) до включения |
| `OWNER_CONFIRM_REQUIRED` | `true` | время интервью, деньги и оффер — только после вашего решения |

## Бот-пульт и связь с вами

| Переменная | Что делает |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `BOT_ALLOWED_USER_IDS` | кто может управлять (ваш id от @userinfobot; через запятую). Пусто — бот не выполняет ничего |
| `OWNER_CHANNEL` | куда приходят карточки: `bot` — в бота; `saved` — в «Избранное» вашего Telegram-аккаунта (нужна сессия, шаг 10 установки); `both` — оба |
| `OWNER_TZ` | ваш часовой пояс: по нему идёт расписание и предлагаются слоты интервью |
| `OWNER_DECISION_TTL_HOURS` | через сколько часов неотвеченная карточка протухает (12) |
| `HEALTHCHECK_URL` | внешний сторож healthchecks.io — пишет вам, если бот перестал работать |

## Почта

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `MAIL_TRANSPORT` | `auto` | `auto` — Gmail API, если выполнен вход в Google, иначе SMTP/IMAP; `gmail_api`; `smtp` |
| `SMTP_USER` | — | ваш адрес Gmail (нужен при любом способе) |
| `SMTP_APP_PASSWORD` | — | пароль приложения Google (только для SMTP/IMAP) |
| `SMTP_FROM_NAME` | из профиля | имя отправителя; пусто — `identity.full_name_en` |
| `SMTP_PORT` | `587` | 587 — STARTTLS, 465 — TLS сразу |
| `EMAIL_DAILY_LIMIT` | `80` | потолок писем в день после прогрева |
| прогрев | 40 → +5/день | старт с 40 писем, +5 за каждый день без отбивок |
| `IMAP_ENABLED` | `true` | читать ответы (через Gmail API или IMAP) |
| `EMAIL_AUTO_REPLY_ENABLED` | `true` | отвечать на рутинные письма самому |
| `EMAIL_REPLY_MIN_GAP_MIN` | `30` | не отвечать, если сами писали в этот тред недавно (защита от петли автоответчиков) |
| `INBOX_LOOKBACK_DAYS` | `45` | насколько далеко назад смотреть входящие |

## Переписка и автономность

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `AUTO_REPLY_ENABLED` | `true` | отвечать на рутину: «пришлите резюме», «когда созвон», «спасибо», «где вы работаете» (из `faq`). `false` — только читать и присылать вам |
| `LLM_AUTO_REPLY_ENABLED` | `true` | рутинные ответы живым языком (с гейтом; при ошибке — шаблон) |
| `BOLD_AUTONOMY` | `false` | смелый режим: бот сам отвечает и на технические вопросы (черновик нейросети через гейт правды и самопроверку). Деньги, оффер и время интервью — всегда вам |
| `REVIVE_ENABLED` | `true` | «оживление»: если вы не ответили на карточку за `REVIVE_AFTER_HOURS` (18), бот переклассифицирует застрявший диалог и, если это рутина, ответит сам (не больше `REVIVE_MAX_ATTEMPTS` раз) |
| `GCAL_ENABLED` | `true` | подтверждённое интервью — событие в Google Calendar |
| `GCAL_CREATE_MEET` | `true` | создавать ссылку Google Meet и отправлять её рекрутёру |
| `GCAL_FREEBUSY_ENABLED` | `true` | предлагая слоты, учитывать занятость в календаре |
| `INTERVIEW_DURATION_MIN` | `60` | длительность события интервью |

Ответы на типовые вопросы бот берёт дословно из `faq` вашего профиля —
см. [PROFILE.md](PROFILE.md#faq--ваши-готовые-ответы).

## Нейросети

| Переменная | Что делает |
|---|---|
| `LLM_ENABLED` | `true` — использовать нейросети, если есть ключи; без ключей — шаблоны |
| `GEMINI_API_KEY`, `GROQ_API_KEY`, `OPENROUTER_API_KEY`, `CEREBRAS_API_KEY`, `MISTRAL_API_KEY`, `GITHUB_MODELS_TOKEN` | ключи бесплатных тарифов; достаточно одного-двух |
| `LLM_PROVIDERS` | порядок или ограничение провайдеров через запятую; пусто — штатный порядок с переходом к следующему при лимите |
| `LLM_*_MODEL` | модель для провайдера; значения по умолчанию рабочие |
| `LLM_REDACT_PII` | `true` — телефоны и адреса вырезаются перед отправкой текста в нейросеть |
| `LLM_CLASSIFY_ENABLED` | второе мнение нейросети для неоднозначных входящих (отказ, непонятное) |

Нейросеть никогда не решает, что правда: каждый её текст проходит гейт правды,
а при отказе уходит шаблон.

## Источники вакансий

| Переменная | Что делает |
|---|---|
| `DISABLED_SOURCES` | какие job-борды и API не собирать, через запятую. Борды: `remoteok`, `arbeitnow`, `himalayas`, `jobicy`, `remotive`, `workingnomads`, `wwr`, `wwr_backend`, `wwr_fullstack`, `wwr_devops`, `wwr_product`, `remotepython`, `cryptojobs`, `habr`, `euremote`, `fourdayweek`, `ergodotisi`; API: `trudvsem`, `workable`, `muse`. По умолчанию выключены `trudvsem,ergodotisi`. Telegram-каналы, HN, Reddit и ATS-фиды этой настройкой не выключаются |
| `MAX_VACANCY_AGE_DAYS` | вакансии старше N дней не брать (21) |
| `DISCOVER_ENABLED` | искать новые Telegram-каналы с вакансиями |
| `DISCOVER_MIN_FRESH7`, `DISCOVER_MIN_CONTACTS` | критерии «живого» канала: свежих постов за 7 дней и постов с контактом |
| `REDDIT_CLIENT_ID`, `REDDIT_CLIENT_SECRET` | Reddit Data API (приложение типа «script» на reddit.com/prefs/apps); пусто — источник пропускается |
| `CAREERED_*` | careered.io — нужен ваш токен из браузера (инструкция в `.env.example`) |

Список Telegram-каналов — `channels_verified.json`; обновить и проверить:

```bash
docker compose exec autopilot python -m jobhunter.ingest.discover --list
docker compose exec autopilot python -m jobhunter.ingest.discover --apply
```

## Отклики через формы (ATS)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ATS_DAILY_LIMIT` | `5` | сколько откликов в день подавать в Ashby через их публичный API. `0` — выключить |
| `APPLY_PREP_DAILY_LIMIT` | `25` | сколько форм в день готовить для ручного отклика (Greenhouse, Lever) |

Ashby подаётся только если **каждое** обязательное поле заполняется фактами
из профиля. Кастомный вопрос, анкета о гражданстве, дополнительный файл —
отказ от подачи целиком, заявка уходит в вашу ручную очередь.

## Прямые письма руководителям

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `DIRECT_ENABLED` | `false` | письма CTO и основателям по **опубликованным** адресам (сайт компании, публичный профиль GitHub, Hacker News); у каждого адреса хранится ссылка на источник |
| `DIRECT_DAILY_LIMIT` | `10` | потолок в день |
| `DIRECT_RAMPUP_DAYS` / `DIRECT_RAMPUP_LIMIT` | `2` / `5` | первые дни — не больше N писем |
| `GITHUB_TOKEN` | — | токен GitHub без прав: поднимает лимит API с 60 до 5000 запросов в час |
| `TAVILY_API_KEY` | — | поиск страниц, где руководитель сам опубликовал адрес (1000 запросов в месяц бесплатно) |

Две отбивки за день ставят канал на паузу. Адреса не угадываются и не
проверяются на почтовом сервере.

## Telegram-аккаунт

| Переменная | Что делает |
|---|---|
| `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `TELEGRAM_PHONE` | ключи с my.telegram.org и ваш номер (шаг 10 установки) |
| `TELEGRAM_COLD_ENABLED` | холодные сообщения; по умолчанию выключены |
| `TG_FOLDER_ENABLED`, `TG_FOLDER_NAME` | складывать диалоги, куда писал бот, в отдельную папку Telegram («Работа») |
| `SENT_ARCHIVE_ENABLED` | копия каждого отправленного сообщения в `out/logs/sent/ДАТА.md` и `.jsonl` |

Темп холодных сообщений (если включены): не чаще одного нового адресата в
30 минут, только днём; при первом сигнале антиспама Telegram (PeerFlood)
отправка останавливается, при втором — переходит в ручной режим. Каждое утро
бот сам спрашивает @SpamBot о состоянии аккаунта.

## Под другую профессию

Код, а не `.env`:

- `jobhunter/match/scorer.py` — `FIT_ROLES` (ваши роли), `MISFIT_ROLES`
  (точно не ваши), `NON_ENGINEERING_ROLES`;
- `lexicon/tech_terms.txt` — словарь технологий, которые узнаёт гейт;
- `jobhunter/ingest/boards.py`, `tgchannels.py` — запросы к бордам и каналы.

После правки кода: `docker compose build migrate && docker compose up -d`.
