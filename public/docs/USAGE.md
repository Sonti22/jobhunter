# Ежедневная работа

Бот работает сам по расписанию. От вас нужно одно: отвечать на карточки, когда
бот чего-то не может решить сам. Всё остальное — по желанию.

## Бот-пульт в Telegram

Команды (они же — кнопки на главном экране):

| Команда | Экран |
|---|---|
| `/start` | главный экран: воронка, что ждёт решения, состояние отправки |
| `/tasks` | «нужно сделать» — ответы рекрутёров, ошибки, протухшие карточки, по пять дел |
| `/cards` | карточки, которые ждут вашего решения |
| `/interviews` | ближайшие интервью |
| `/stats` | статистика и график отправок по дням |
| `/queue` | очередь на отправку, кнопка «одобрить топ-10» |
| `/sending` | почему заявка ждёт: лимит, пауза, стоп-кран, ближайший запуск |
| `/reading` | насколько полно прочитаны каналы, Telegram-диалоги и почта |
| `/results` | результаты за 90 дней: ответы, интервью, офферы, отказы |
| `/tracks` | направления поиска (Backend / AI–ML / Tech Lead) и фильтры |
| `/manual` | вакансии для ручного отклика через форму компании |
| `/outreach` | Telegram-отклики, которые вы отправляете сами (см. ниже) |
| `/channels` | Telegram-каналы-источники |
| `/stop`, `/go` | стоп-кран: остановить и возобновить всю отправку |
| `/help` | справка |

Бот держит одно сообщение-экран и правит его, поэтому чат не забивается
сводками. Уведомления приходят отдельно: рекрутёр ответил, назначено интервью,
сработал стоп-кран, сигнал антиспама Telegram, итог дня.

## Карточки: когда бот спрашивает вас

Бот сам отвечает только на рутину. Карточка приходит, если:

| Ситуация | Что в карточке | Ваши кнопки |
|---|---|---|
| Рекрутёр предложил время интервью | распознанные слоты | `✅ пт 29.08 16:00`, `🕒 Другое время`, `❌ Не подходит` |
| Вопрос о зарплате, оффер | текст рекрутёра | ответить своим текстом, закрыть |
| Технический вопрос (если `BOLD_AUTONOMY=false`) или непонятный ответ | текст и черновик ответа, прошедший гейт правды | «Отправить черновик», свой текст, закрыть |

Нажатие принимается сразу, а сообщение рекрутёру уходит в течение пяти минут:
пишет процесс автопилота, бот только ставит решение в очередь. Результат
дописывается в ту же карточку.

После подтверждения интервью бот отправляет рекрутёру подтверждение (со
ссылкой Google Meet, если включено), создаёт событие в календаре с
напоминаниями за сутки и за час и обновляет `out/interviews.ics`.

Карточка без ответа протухает через `OWNER_DECISION_TTL_HOURS` (12 часов).
Если вы в это время были недоступны, бот продлевает срок. При включённом
`REVIVE_ENABLED` застрявший рутинный диалог бот оживит сам.

### Команды в «Избранном»

Если `OWNER_CHANNEL=saved` или `both`, карточки приходят в «Избранное»
(Saved Messages) вашего Telegram-аккаунта, и отвечать можно командами:

```
/ok 12             подтвердить вариант 1 из карточки 12   (/ok 12 2 — вариант 2)
/time 12 29.08 16:00   предложить своё время
/no 12             отказаться от предложенного времени
/send 12           отправить черновик как есть
/say 12 текст      отправить свой текст
/skip 12           закрыть карточку без действий
/status  /stop  /go  /help
```

## Ручные отклики

**Формы компаний (`/manual`, http://127.0.0.1:8765/manual).** Вакансии из
Greenhouse, Lever и других ATS, где отклик — только через форму. Бот оценил
вакансию, подготовил резюме и письмо; вы открываете ссылку, прикладываете файл
и отправляете. Формы намеренно не заполняются автоматически: там отсеивающие
вопросы (право на работу, стаж, релокация), и неверный автоответ закрывает
компанию навсегда. Исключение — Ashby с простой формой (см.
[CONFIGURATION.md](CONFIGURATION.md#отклики-через-формы-ats)).

**Telegram, отправляю сам (`/outreach`).** Если холодная рассылка выключена
(по умолчанию), бот всё равно готовит отклики на вакансии с Telegram-контактом
и выдаёт их вам по одному: ник рекрутёра, готовое сообщение и PDF-резюме.

1. Кнопка «Открыть @ник с текстом» открывает чат с подставленным текстом (не
   отправляет его). Не подставился — «Текст отдельно», скопируйте.
2. Отправьте сообщение и резюме сами.
3. «✅ Всё отправил → следующий» и подтверждение. Бот запишет отметку и
   пришлёт следующий отклик.

«Не подходит» — убрать карточку; «Не получилось» — убрать без повтора и
поставить выдачу на паузу (возобновить — `/outreach`). Ошибочную отметку
можно отменить в течение 15 минут. Отметка «отправил» — это ваши слова, а не
подтверждение доставки: бот не притворяется, что знает больше.

## Веб-панель

http://127.0.0.1:8765 — доступна только с этого компьютера.

| Страница | Что там |
|---|---|
| `/` | сводка |
| `/queue`, `/approve` | очередь на одобрение, фильтры, одобрить или отклонить |
| `/applications/<id>` | полная история заявки: вакансия, письмо, резюме, переписка; «вернуть в очередь» |
| `/attention` | то же, что `/tasks` в боте |
| `/sending` | причины ожидания и ближайший запуск |
| `/reading` | полнота чтения источников и ответов |
| `/outcomes`, `/results` | результаты откликов |
| `/stats` | графики |
| `/manual`, `/manual-telegram` | ручные отклики |
| `/sent` | что и кому отправлено |
| `/blacklist` | компании, которым не писать |
| `/killswitch` | стоп-кран |

JSON для своих скриптов: `/api/summary`, `/api/applications`, `/api/sending`,
`/api/attention`, `/api/reading`, `/api/outcomes`, `/api/results`.

## Стоп-кран

Остановить всю отправку немедленно — любой способ:

- `/stop` в боте (возобновить — `/go`);
- кнопка на странице `/killswitch` панели;
- создать файл `STOP_SENDING.flag` в томе данных.

Проверяется **перед каждым** сообщением, а не раз на партию. Сбор вакансий и
чтение ответов при этом продолжаются.

## Ручные команды

Пока работают контейнеры, все команды — только через `docker compose exec`
(иначе появится второй процесс на той же базе и сессии Telegram):

```bash
docker compose exec autopilot python -m jobhunter.ingest.all_sources       # собрать вакансии сейчас
docker compose exec autopilot python -m jobhunter.pipeline                 # подготовить письма и резюме
docker compose exec autopilot python -m jobhunter.outreach.approve --list  # что готово к отправке
docker compose exec autopilot python -m jobhunter.outreach.approve --show 260
docker compose exec autopilot python -m jobhunter.outreach.mailer          # отправить письма сейчас
docker compose exec autopilot python -m jobhunter.ingest.discover --list   # найденные каналы
docker compose exec autopilot python -m jobhunter.ops check                # целостность базы
docker compose exec autopilot python -m jobhunter.ops export --path /out/export.json
```

## Где искать следы

- `out/logs/` — логи; `out/logs/sent/ДАТА.md` — кому, когда и что отправлено;
- `out/cv_out/` — резюме, собранные под вакансии;
- `out/interviews.ics` — интервью для любого календаря;
- в Telegram — папка «Работа» со всеми диалогами, куда писал бот.

## Хорошая практика

- **Первую неделю читайте письма в панели** до того, как они уходят: поставьте
  `DRY_RUN=true` или одобряйте вручную через `/queue`.
- **Отвечайте на карточки в тот же день.** Слот на завтра, подтверждённый
  через сутки, хуже честного отказа.
- **Отмечайте результаты** (интервью прошло, оффер, отказ) — по ним бот
  учится, какие письма и источники работают.
- **Раз в неделю** смотрите `/results`: какие источники и письма приносят
  ответы, а какие нет (причины ваших пропусков — `/api/feedback` в панели).
