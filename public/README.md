# jobhunter — автопилот поиска работы

Бот, который каждый день сам ищет вакансии, отбирает подходящие под ваш профиль,
пишет под каждую честное письмо и резюме, отправляет их, ведёт переписку с
рекрутёрами и согласует с вами время интервью. Управление — через личного
Telegram-бота и локальную веб-панель. Всё работает на вашем компьютере в Docker;
ваши данные никуда, кроме выбранных вами сервисов, не уходят.

> **Главный принцип — ни слова неправды.** Бот не может приписать вам навык,
> цифру, компанию или стаж, которых нет в вашем `profile.yaml`: каждый текст
> проходит «гейт правды» и при любом выдуманном факте отклоняется.

## Что умеет

| Этап | Что делает бот |
|---|---|
| **Сбор** | Публичные Telegram-каналы с вакансиями (и автопоиск новых), фиды ATS компаний (Greenhouse, Lever, Ashby), около 15 открытых job-бордов (Remotive, Himalayas, We Work Remotely, Arbeitnow, Хабр Карьера и др.), Hacker News «Who is hiring», Reddit, «Работа России», Workable, The Muse |
| **Отбор** | Оценка вакансии по навыкам и роли из профиля, отсев junior, не-IT и чужого стека, формат работы (удалёнка / офис в вашем городе / переезд), свежесть, дубли |
| **Письмо и резюме** | Короткое письмо под конкретную вакансию (цитирует её требование), PDF-резюме, подогнанное под роль; по желанию — живой язык через бесплатные нейросети |
| **Проверка правды** | Технологии, числа, компании, стаж и уровни сверяются с профилем; выдумка = письмо не уходит |
| **Отправка** | Email (Gmail API или SMTP) с прогревом ящика и лимитами; отклики в Ashby через их официальный публичный API (до 5 в день, только если все поля формы заполняются фактами из профиля); Telegram — ответы тем, кто написал сам (холодная рассылка выключена по умолчанию, см. [безопасность](docs/SAFETY.md)) |
| **Переписка** | Читает ответы, сам отвечает на рутину («пришлите резюме», «когда созвон», «где вы работаете» — вашими готовыми ответами), остальное присылает вам карточкой |
| **Интервью** | Предложенное время → карточка с кнопками → подтверждение рекрутёру, событие в Google Calendar с Meet |
| **Пульт** | Telegram-бот: воронка, статистика, очередь, «нужно сделать», стоп-кран; веб-панель на `127.0.0.1:8765` |

Чего бот **намеренно не делает**: не заполняет анкеты на сайтах компаний
браузером (формы Greenhouse, Lever и другие он готовит, а отправляете вы), не
отвечает за вас на отсеивающие вопросы, не обходит CAPTCHA, не ходит в LinkedIn
и hh.ru, не покупает базы контактов и не подбирает адреса. Подробно —
[docs/SAFETY.md](docs/SAFETY.md).

## Как это выглядит в работе

```
08:45  резервная копия базы           10:30  отправка писем
09:00  поиск новых Telegram-каналов   10:45  отклики в Ashby
09:30  сбор вакансий                  11:15  Telegram (если включено)
09:40  ручная очередь (формы ATS)     12:00  напоминания тем, кто молчит
10:00  письма и резюме под вакансии   16:40  Telegram (если включено)
10:15  одобрение (балл ≥ 55, гейт)    каждые 20 мин с 9 до 21 — чтение ответов
```

Время — в часовом поясе `OWNER_TZ` (по умолчанию Москва).

Вы получаете в Telegram только то, что требует решения: предложенное время
интервью, вопрос о зарплате, оффер, непонятный ответ. Всё остальное бот делает сам.

## Быстрый старт

Полная пошаговая инструкция — **[docs/INSTALL.md](docs/INSTALL.md)** (около часа
в первый раз). Коротко:

```bash
git clone <адрес этого репозитория> jobhunter && cd jobhunter
cp profile.example.yaml profile.yaml      # перепишите под себя
cp .env.example .env                      # ключи и настройки
cp ~/Documents/my_resume.pdf cv_base/resume.pdf
docker compose build migrate
docker compose up -d
```

Минимальная рабочая конфигурация: профиль, Telegram-бот-пульт (токен от
@BotFather) и почта Gmail. Telegram-аккаунт, Google Calendar, нейросети и
остальные источники подключаются по желанию.

## Требования

- Компьютер, который включён днём (бот работает по расписанию с 9 до 21 по вашему времени).
- Docker Desktop (Windows / macOS) или Docker Engine (Linux).
- Python 3.12 на хосте — только для разового входа в Telegram и Google.
- Аккаунт Gmail для писем. По желанию: Telegram-аккаунт, Google Calendar,
  бесплатные ключи нейросетей (Gemini, Groq, OpenRouter, Cerebras, Mistral, GitHub Models).

## Под кого настроено

Отбор ролей (`jobhunter/match/scorer.py`) и словарь технологий
(`lexicon/tech_terms.txt`) настроены под IT: backend, платформа, DevOps, данные,
tech lead, технический продукт-менеджмент. Для другой профессии поправьте списки
ролей в `scorer.py` и словарь — остальное берётся из вашего профиля.

## Разработка

```bash
pip install -r requirements-dev.txt
python -m pytest tests/ -q          # ~1400 тестов, офлайн, на вымышленном профиле
ruff check jobhunter tests
python validate_profile.py          # проверка вашего profile.yaml
```

Тесты используют `profile.example.yaml` (вымышленный кандидат) и никогда не
ходят в сеть. `tests/test_profile_real.py` дополнительно проверяет ваш
настоящий `profile.yaml`, если он есть.

## Ответственность

Вы отправляете сообщения от своего имени и отвечаете за них сами. Соблюдайте
правила площадок и законы о персональных данных — см. [docs/SAFETY.md](docs/SAFETY.md).
